It doesn't visit the web.
It operates it.

A browser agent doesn't read about the web. It drives it — sees the screen, moves the cursor, clicks, types, submits. The question was never whether it could. The question is what it's allowed to do.

Three verbs — and a fourth

See. Decide. Act. Stop.

Every browser agent runs the same loop. The fourth verb is the one that makes it safe to own.

01 · See

Screenshot in

The agent looks at the page the way you do — pixels, not APIs. No integration required; if a human can use the site, so can it.

02 · Decide

Model chooses

Where to click, what to type, when to scroll. One decision per screenshot, hundreds of steps per task.

03 · Act

Cursor out

Click, type, scroll, submit. The same affordances a person has — which is the power, and the problem.

04 · Stop

Envelope holds

Looking is free. Committing is not. Payment, submission, sending, deleting — those cross the envelope, and the envelope decides.

That fourth verb is native to this name. A browser agent's envelope is not an add-on; the browser is the boundary it operates inside. Read anything. Change only what you're bound to change.

The record

Every frontier lab built one. Then they all folded.

The browser agent went from research preview to infrastructure in eighteen months — and the standalone products didn't survive the trip.

WhenWhat happened
Oct 2024Anthropic ships Computer Use in beta with Claude 3.5 Sonnet — screenshot in, cursor actions out. Partners include Asana, Canva, DoorDash, and Replit.
Dec 2024Google unveils Project Mariner, a Gemini 2.0 Chrome-extension prototype for trusted testers. It scores 83.5% on the WebVoyager browsing benchmark — state of the art at launch, per Google.
Jan 2025OpenAI launches Operator, a research preview for ChatGPT Pro ($200/month, US only), powered by its Computer-Using Agent model. OpenAI reports 87% on WebVoyager, 58.1% on WebArena, 38.1% on OSWorld.
Mar 2025Browser Use raises a $17M seed led by Felicis, with Y Combinator and Paul Graham — the open-source library that turns any model into a browser agent.
Jul–Aug 2025Operator folds into ChatGPT Agent (July 17); the standalone product is retired August 31.
May 2026Mariner shuts down (May 4). Its technology moves into other Google products — Gemini Agent, AI Mode, computer use in the Gemini API.

The honest turn: the products folded, the capability didn't. What survives is the layer — open-source frameworks, hosted browser infrastructure, computer-use APIs — and the name of the layer is the category term itself.
